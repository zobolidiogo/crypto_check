Sobre o crypto.check

O crypto.check é uma plataforma web desenvolvida para simulação de investimentos em criptomoedas utilizando dados reais de mercado em tempo real. O projeto foi criado com o objetivo de unir desenvolvimento full-stack, análise de dados e experiência do usuário em uma aplicação prática e funcional.

A aplicação foi desenvolvida como projeto final do curso CS50x — Introduction to Computer Science, da Harvard University. Durante o desenvolvimento, o foco principal foi construir uma plataforma completa, integrando backend, banco de dados, autenticação de usuários, consumo de APIs externas e visualização dinâmica de dados financeiros.

O sistema permite que usuários criem contas, realizem compras e vendas simuladas de criptomoedas, acompanhem seu portfólio virtual e visualizem o histórico completo de transações realizadas. Além disso, a plataforma exibe informações atualizadas do mercado cripto, incluindo preços em tempo real e gráficos históricos interativos.

Os dados das criptomoedas são obtidos através de APIs públicas de mercado, permitindo que os preços exibidos reflitam oscilações reais do mercado financeiro. Dessa forma, o projeto busca oferecer uma experiência próxima de uma plataforma real de investimentos, mas voltada para fins educacionais e de aprendizado.

No backend, a aplicação utiliza Python com Flask para gerenciamento de rotas, autenticação de usuários, regras de negócio e integração com banco de dados. O armazenamento das informações é realizado com PostgreSQL, hospedado em nuvem através do Supabase.

Já no frontend, foram utilizados HTML, CSS e JavaScript para construção da interface, juntamente com Chart.js para renderização de gráficos interativos de preços e evolução de mercado. O projeto também possui foco em responsividade, organização visual e experiência do usuário.

Entre as principais funcionalidades do sistema estão:

  • Cadastro e autenticação de usuários
  • Simulação de compra e venda de criptomoedas
  • Controle de saldo virtual
  • Histórico completo de transações
  • Visualização de portfólio
  • Integração com APIs de mercado
  • Gráficos interativos de preços
  • Atualização de dados em tempo real

O crypto.check representa não apenas um projeto acadêmico, mas também uma aplicação prática voltada ao aprendizado de desenvolvimento web, engenharia de software e manipulação de dados financeiros. O projeto continua em evolução, com melhorias constantes de interface, performance e novas funcionalidades.

Tecnologias utilizadas

Python Flask Jinja PostgreSQL Supabase JavaScript Chart.js HTML CSS Render CoinGecko API
